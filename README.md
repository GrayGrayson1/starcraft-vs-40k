# StarCraft vs Warhammer 40,000 — Convergence Databank

Thirty-six like-for-like unit pairings between StarCraft and Warhammer 40,000.

StarCraft II stats are extracted from the game's own balance data files (56 units).
Warhammer 40,000 stats are read from current 10th-edition datasheets (54 datasheets),
including published base sizes. Comparative charts show each unit's percentile rank
*within its own game's roster* — the two rule systems share no units, so raw values
are never plotted on a single scale.

**Live page:** https://graygrayson1.github.io/starcraft-vs-40k/
